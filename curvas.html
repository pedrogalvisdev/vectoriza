Curvas de nivel

Aprende a representar funciones de dos variables mediante curvas en el plano.

1. ¿Qué es una curva de nivel?

Una función de dos variables tiene la forma f(x,y). Para obtener una curva de nivel, igualamos la función a una constante k:

f(x, y) = k

Al cambiar el valor de k, obtenemos diferentes curvas. Cada una representa los puntos del plano donde la función tiene el mismo valor.

2. Ejemplo paso a paso

Encuentra la curva de nivel de la función:

f(x, y) = x² + y²

Paso 1. Elegimos el nivel k = 4 y lo igualamos a la función.

x² + y² = 4

Paso 2. Identificamos la ecuación. Corresponde a una circunferencia con centro en (0, 0) y radio 2.

Paso 3. Comprobamos algunos puntos:

  • (2, 0): 2² + 0² = 4.
  • (0, 2): 0² + 2² = 4.
  • (-2, 0): (-2)² + 0² = 4.
  • (0, -2): 0² + (-2)² = 4.
Conclusión: los cuatro puntos cumplen la ecuación y pertenecen a la circunferencia de radio 2.

3. Practica lo aprendido

Para la función f(x,y) = x² + y², ¿cuál es la curva de nivel cuando k = 9?

Selecciona una respuesta y comprueba.
