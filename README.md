# Vectoriza
### Plataforma web para el aprendizaje de Cálculo Vectorial

## Descripción
Vectoriza es una plataforma web educativa que facilita el aprendizaje de conceptos de Cálculo Vectorial mediante explicaciones, ejemplos, cuestionarios interactivos y gráficas.

## Objetivo general
Desarrollar una plataforma web interactiva que apoye el aprendizaje de Cálculo Vectorial mediante recursos didácticos y ejercicios prácticos.

## Objetivos específicos
- Explicar conceptos matemáticos con ejemplos paso a paso.
- Practicar mediante cuestionarios interactivos.
- Visualizar curvas de nivel y observar cómo cambian al modificar el valor de k.
- Consultar un resumen del progreso guardado en el navegador.

## Temas
- Superficies cuádricas.
- Secciones cónicas.
- Curvas de nivel de funciones de dos variables.

## Tecnologías
- HTML5.
- CSS3.
- JavaScript.
- Canvas para la representación gráfica.
- LocalStorage para guardar resultados localmente.
- Git y GitHub para el control de versiones.

## Ejecución
Abre una terminal en la carpeta del proyecto y ejecuta:

    python3 -m http.server 8000

Después visita http://localhost:8000 en tu navegador.

## Limitaciones
El progreso se guarda en el navegador actual. No hay cuentas de usuario ni sincronización entre dispositivos.

## Autores
Agregar los nombres de todos los integrantes del equipo antes de la entrega.
